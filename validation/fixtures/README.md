# Client validation fixture

`client-world.zip` is the owned vanilla Minecraft 1.21.1 creative test world
used by the recorded client validation. Its 13 files match
`client-world.manifest.json`; it contains no playerdata, account information,
or session lock. The original was generated by a normal dedicated-server boot
and controlled stop. This is test-world data, not a mod or a Minecraft binary.

Extract it into a separate scratch directory, then set `pristineWorldPath` in
the ignored `target-local.properties` to that extracted directory. The
validation launcher treats it as read-only, copies it into its owned runtime,
and checks the original again after the client exits.

```powershell
Expand-Archive -LiteralPath fixtures/client-world.zip `
  -DestinationPath S:/modporter-validation-fixtures/vanilla-1.21.1
```
